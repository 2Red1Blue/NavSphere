# 双模型诊断摘要

分析会话：Codex `01a07f2b-8a24-7803-b618-cba2a4f9bfda`；Claude `f04f345a-2156-44e1-9bfa-8a64df4f543d`。

## 结论

暂不完整注入 Think。先修复证据选择与深度稿契约，再以相同证据和预算 A/B 测试一份不超过 300 字的显式规划协议。

## 证据

- 原文提取约 10,175 字符、1,707 词；写手证据包固定为前 4,000 字符，并在实验、超过 85% 的调查结果、伤害因素和道德化风险之前截断。
- 写作规范明确要求 300–600 字短摘要；schema 限制 2–4 条事实、analysis 最多 240 字、总长最多 1,400 字。
- 实际稿 376 字，4 条事实，analysis 60 字，由 `gpt-5.4-mini` 生成；`gpt-5.6-sol` 对九项主张审查通过。公开渲染完整显示了结构化稿件，没有截断。
- 审稿只检查已有主张是否有支持，没有检查原文重要内容是否遗漏。

## 建议目标

`不可变全文抓取 → 有偏移和哈希的代表性选段 → 覆盖检查 → 显式短规划 → 深度稿 → 支持性与完整性双维审稿 → 发布`

规划是可验证的结构化产物，不是隐藏思维链。隐藏推理不要求、不保存、不公开。

## 最小实验

对同一组 6–12 篇文章固定模型、证据和正文预算，比较无规划与紧凑规划两组；关键事实覆盖至少翻倍、支持率不下降、耗时和 token 中位数不超过 1.3 倍才进入有限试点。全部停在待审，不发布、不推送。

已发布文章可以在新证据版本下生成新的修订候选，但必须重新写作、审稿、批准并用线上当前 revision 条件更新；是否重发飞书需另行决定，不能覆盖旧审计记录。
