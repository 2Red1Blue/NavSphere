# 开源文章写作流程调研结论

日期：2026-09-08。范围为官方文档、论文与关键源码；版本与来源见 source-notes.md。没有安装这些项目或运行同题端到端生成评测，没有修改生产写作链。

## 对之前方案的校正

修复证据前缀截断、增加内容覆盖检查是有直接依据的。完整输入可容纳的单篇原文通常应优先于代表性选段；超预算文档再分段覆盖和按节检索。代表性选段也可能遗漏结论，不能把截断问题换成未经验证的抽样问题。

不能将独立规划 Agent、300 字计划、固定文章字数、多路并行和一组硬编码实验比例作为全部文章的强制流程。单篇原文解读通常用一条轻流程即可；多源专题才适合扩展研究任务。

`facts/analysis/caveats` 适合作为审核所需结构。公开成稿需要自然标题、段落、论证和与内容相符的章节。新稿结构须有版本并兼容旧稿验证；单改公开模板无法生成缺失的深度。

## 可迁移机制

1. **STORM：问题和大纲驱动写作。** 使用不同角度提出问题，依章节检索资料并生成正文；借鉴预写作与章节证据映射。它面向维基式长文，官方亦承认成稿仍需编辑，不宜把整个多视角系统套到每则新闻。
2. **GPT Researcher：分节写作与去重。** DetailedReport 在每一节写作时参考已写内容和标题；当前该实现顺序处理子题。适合长专题控制重复，不等于每个短篇都需多 Agent。限定 URL／本地文档研究可迁移到现有 capture。
3. **Open Deep Research：发现缺口后决定下一步。** research_brief、主管、研究员、保留来源的压缩和最终报告各有职责。think_tool 是显式反思工具，源码仅返回输入的记录确认，不是新的事实验证服务，也不是本地 Think Skill。其最终报告是一次综合调用，不能泛化为与 STORM 相同的逐节并行写作。
4. **DeerFlow 2：文体决定产出。** 当前 newsletter Skill 分日报、周刊、深度稿和行业简报，区分重点条目与短讯；研究 Skill 要求重要来源全文阅读和综合检查。可借鉴专项 Skill 和文体策略，暂不迁移整套沙箱／通用 harness。
5. **Anthropic 生产经验：预算和整体评价。** 并行适用于独立研究方向；审核可用一个整体 rubric 同时看准确性、引用、完整性和效率。多模型调用数量不直接等于文章质量。

## 推荐的本项目流程

原始网页保留完整快照。先按输入预算选择全文阅读或覆盖所有章节的分段阅读，再选文体：

- **简讯**：紧凑事实与意义，面向列表和日报。
- **原文解读**：围绕原文论证、方法、结果和局限写连贯正文；需要时检索补充上下文。
- **多源专题**：先列子问题和资料缺口，再有限并行检索和分节写作，最后统一编辑。

给写手的简短任务说明应明确读者、文章问题、关键材料、拟定章节和未解决问题。可在输入完整后试用精简 Think 方法，但无需每篇多调用一个模型、也不输出隐藏推理过程。

审稿用完整来源或带全文覆盖说明的来源结构，同时检查已写事实与重要遗漏；审核员仅看与写手相同的不完整前缀不足以发现漏读。只修复具体失败段落；必要的证据缺口先回到研究阶段。

以经审定正文为主版本，派生网站摘要和飞书卡片，并绑定正文版本以保持一致。审核数据和来源索引持久化，公开呈现用自然段及必要归因；移除 E1/版本号不应抹除证据局限或夸大来源结论。

## 这篇 Psyche 文章应如何体现深度

在阅读全文后，正文至少应讲清：自我义务与个人偏好的区别；支持与反对的理由；作者如何研究日常道德判断；报告的结果与样本人群范围；自我道德化的动力与苛责风险；描述性调查为何不直接证明规范性义务。这些是拟写问题，不是固定六段模板或已完成的新文章。

## 改造优先级和实验

1. 修复完整阅读和输入覆盖；为单篇原文增加自然章节成稿模式。
2. 增加事实支持、重要遗漏、重复及表达质量的整体审核；从正文派生摘要。
3. 使用相同来源、模型和长度预算比较有／无精简规划的输出；固定事实清单、检查数字与限定语，再评估是否增加规划调用。

先用该篇已保存全文验证最明显的漏读问题，再用少量不同体裁样例观察泛化。前述 6–12 篇、覆盖翻倍、1.3 倍成本等不是外部公认标准，也不是统计显著性保证。验收应基于关键内容是否覆盖、无依据断言是否增加，以及实际费用与等待时间。

## 审阅与限制

Codex 与 Claude CLI 已并行给出只读分析，两者都提示单篇文章不应套用复杂研究系统。对分析中将 Open Deep Research 泛化为逐节生成的说法，按实际源码作了纠正。

Claude CLI 本次虽显式请求 claude-sonnet-4-6，持久化消息实际 model 字段仍为 glm-5-3-flash，因此不计为 Claude 独立审阅。此前同类运行被报告为 Claude 双审通过的说法应纠正。没有为此修改全局模型路由或凭证；本轮结论依赖上述可直接检查的官方来源。
