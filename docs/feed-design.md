# Feed 阅读界面

## 2026-09-07：透明建筑式专题空间（本次上线方向）

参考：https://jp.pinterest.com/pin/961448220464782789/ 。用户确认直接定稿、实施并部署。保留参考的透明展厅、错落层级和低饱和光源，转译为真实专题导航；并非把建筑海报逐像素变成网页。

- `/feed/topics` 的空间视图每组最多六个专题，分组按钮覆盖接口返回的全部专题；列表与搜索提供直接入口。
- 选中状态写入 URL，专题名经 URLSearchParams 编码。阅读面板按专题请求现有公开接口，取消过期请求，并按专题隔离状态，避免快速切换时展示上一专题文章。
- 阅读面板保留最多 20 个专题的短时缓存，60 秒有效；未改变后端查询、权限、数据库和归档任务。
- 移动端使用独立按钮网格，并在更换专题后定位到阅读面板。关闭动态效果或系统要求减少动态效果时，取消视角变化与平滑定位。
- 素材失败降级为按钮网格；元数据失败、文章失败、空专题、空搜索分别显示明确状态。
- 首页通过紧凑专题入口复用同一素材与已经取得的专题元数据，没有额外首页专题接口请求。
- 修复原热点来源链接进入 Feed 后未应用 `source` 筛选的问题。

### 素材与性能

`public/images/feed/topic-atrium-v1.webp`：1024×1024，67,892 bytes，六个玻璃展厅。内置 Image Gen 原创生成，工具无法附加会话参考图，因此依据已经观察的构图特征生成，而非编辑或复制原图。无需 WebGL、实时渲染引擎或额外依赖。交互按钮是真实 HTML，不把导航文字烘焙进图片。

生成提示词要点：近黑背景、中央六个错落的等距透视玻璃展厅、银色细结构、珍珠紫与冰蓝微光、空展台与抽象纸张／技术物件、精细建筑模型风格；无人物、文字、Logo、城市天际线和高饱和霓虹。

### 部署边界

沿用 Cloudflare Pages 项目 `navsphere`、生产分支 `main`。此次发布不创建云资源、不运行远端迁移、不改写文章、不发飞书消息。生产发布前保留上一部署 ID，完成本地浏览器验证后构建 Pages 产物；发布后检查生产入口、专题切换、文章来源与公开接口。

## 2026-09-07：赛博朋克视觉追加

按用户明确选择，覆盖前一版灰白／墨绿方向：默认深墨底，霓虹青作为交互色，电紫标记装饰切角。保留小字号、完整中文标题和日期分组。

- 首页顶部光带持续缓慢扫描；文章悬停与键盘聚焦时点亮渐变边缘；品牌字标仅在悬停时做 360ms 微弱错位，不闪烁正文。
- 右下角可关闭特效，偏好只存于本机。系统 `prefers-reduced-motion` 优先，禁用动画及伪元素动画。
- Feed 主题使用独立的 `navsphere-feed-theme` 存储项，不修改全站主题；离开 Feed 时清理文档上的局部主题属性。
- 纯 CSS 装饰，不使用视频背景、WebGL、外部资源或新增付费服务。装饰层不接收点击，扫描线不覆盖正文。

此前的 `frontend-design` 默认反对霓虹配色；本次按用户明确风格要求覆盖该默认建议，继续采用其可读性与可访问性要求。

## 2026-09-07：紧凑排版与渐进式阅读

用户反馈：巨幅宋体标题挤占首屏，「信号志」「今日信号」等命名难以理解。新版保留 NavSphere 品牌，使用「最新动态、精选、日报、热点榜、专题」。

参考 Pinterest 的 [WorldNews](https://www.pinterest.com/pin/320951910961120010/) 中的侧栏与资讯列表层级；未复制图像资产、社交模块或具体页面。中文阅读体验优先于装饰性排版。

- 日期分组、单栏正文、窄侧栏；白灰底色与墨绿操作色，支持深色主题。
- 页面标题 28–32px，列表标题 20–22px，速览标题 18px，详情标题 28–40px；保留完整标题，不以截断修饰长标题。
- 阅读模式展示摘要；速览隐藏摘要；「展开导读」就地显示完整摘要和推荐理由，无额外接口请求。
- 搜索输入防抖 300ms，支持 Enter 提交与 `/` 聚焦。筛选请求取消旧请求，旧内容不冒充新筛选结果，失败可重试。
- 密度选择指示器、导读展开、主题图标及列表进入使用有限的过渡。适配 `prefers-reduced-motion`，不使用滚动劫持或循环装饰动画。
- 移动端筛选使用现有 Radix Dialog，提供焦点约束、Escape 关闭和焦点恢复。

仅改变 Feed 的展示与客户端交互。原文来源、安全 Markdown、图片加载授权、编辑稿校验、发布许可与 API 数据契约保持不变。未添加依赖、数据库迁移或云资源。

## 验证方式

执行类型检查、lint、现有阅读器和数据契约测试与生产构建。浏览器使用线上公开文章快照检查长中文标题、密度切换、导读展开、搜索、移动端焦点管理、主题切换及减少动态效果设置。快照验证不代表本地 D1 迁移或线上发布已完成。

Skill 应用：`frontend-design` 用于阅读层级和文字设计；`animate` 用于状态反馈、过渡时长和 reduced-motion；`skill-task` 完成本地/云端检索与当前执行器内的验证。云端 `design-spells` 仅检索和查看元数据，没有安装或应用。
